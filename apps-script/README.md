# Actividades de barrios

1. Crear un proyecto de Apps Script y pegar `Code.gs`.
2. En **Configuración del proyecto → Propiedades del script**, agregar `ADMIN_PASSWORD` con la contraseña elegida para el panel.
3. Implementar como **Aplicación web**:
   - Ejecutar como: la cuenta propietaria.
   - Acceso: cualquier usuario.
4. Copiar la URL terminada en `/exec` y colocarla en `barrios/config.js`.

La contraseña se valida dentro de Apps Script y nunca se guarda en el repositorio.
